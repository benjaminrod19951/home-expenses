# הוצאות הבית — v24.48

אתר לניהול הוצאות והכנסות משותף לבית או לעסק: ייבוא קובצי בנק לאומי וכרטיסי אשראי, הזנה קולית מהירה, קטגוריות, תקציבים, השוואות ותכנון קדימה.

**מבנה:** React + Vite · נתונים ב-Supabase · אירוח ב-Vercel · תמלול ופענוח קולי דרך Groq (`api/`).

## העלאה לאוויר
1. מחליפים את תוכן התיקייה במאגר המקומי בקבצים האלה.
2. ב-GitHub Desktop: Commit ואז Push.
3. Vercel בונה ומפרסם אוטומטית.

משתני סביבה ב-Vercel (כבר קיימים): `SUPABASE_URL`, `SUPABASE_ANON_KEY` (או `SUPABASE_PUBLISHABLE_KEY`), `GROQ_API_KEY`. ראו `env.example`.

## בדיקה לפני העלאה (מומלץ)
```
npm install      # פעם אחת
npm run check    # מריץ את הבדיקות האוטומטיות ובונה את האתר
```
אם משהו נכשל, לא מעלים.

## איפה מה נמצא
| קובץ | מה יש בו |
|---|---|
| `src/App.jsx` | המסך הראשי: טעינת נתונים, לשוניות, פעולות על הנתונים |
| `src/components/` | כל חלון/פאנל בקובץ משלו (הזנה מהירה, עריכת הוצאה, ניתוח סופר, טבלאות…) |
| `src/lib/finance.js` | מה נחשב הוצאה/הכנסה, זיהוי בתי עסק |

| `src/lib/insights.js` | השוואות, צפי לסוף חודש, כפילויות, חיובים קבועים |
| `src/lib/db.js` | טעינת כל השורות מ-Supabase (מעבר למגבלת 1,000) |

| `src/lib/transactions.js` | הזנה ידנית, העברה בין מרחבים, מחיקה, סימון כפילות (+ `services/transactionsService.js`) |

| `src/importers.js` | קריאת הקובץ שהועלה |
| `api/` | שרת התמלול והפענוח (דורש משתמש מחובר) |
| `tests/` | בדיקות אוטומטיות (`npm test`) |
| `supabase/` | מבנה מסד הנתונים; סקריפטים ישנים ב-`archive/` — לא להריץ שוב |
