# v24.47 — תיקון הזנה קולית

**התקלה:** בהקלטה הופיעה השגיאה `prompt length must be 896 characters or fewer, but provided prompt contains 1058 characters`, גם בהקלטה קצרה.

**הסיבה:** v24.43 הגבילה את רשימת המילים שנשלחת למנוע התמלול ל-650 *תווים*. Groq סופר *בתים* (UTF-8), וכל אות בעברית היא 2 בתים, כך ש-650 תווים בעברית הם בערך 1,060 בתים. לאורך ההקלטה אין קשר לזה. ככל שההיסטוריה שלך גדלה, הרשימה התארכה והגיעה לגבול.

**התיקון:**
- הרשימה מוגבלת עכשיו ל-800 בתים (`api/_whisperPrompt.js`).
- אם Groq בכל זאת דוחה את האורך, ההקלטה מתומללת שוב בלי רשימת המילים, במקום להיכשל.
- נוספו 4 בדיקות, כולל בדיקת רגרסיה להיסטוריה ארוכה בעברית.

אין שינוי במסד הנתונים. אם עוד לא הרצת את שני קובצי ה-Migration של v24.45 ו-v24.46, ההוראות ב-`supabase/README.md`.
